# An Automated Payroll and Attendance Monitoring System

A desktop-based payroll and attendance management system designed to automate employee attendance tracking, payroll computation, and administrative reporting.

## Project Overview

This system aims to reduce manual payroll processing by providing automated computation of salaries, deductions, allowances, incentives, overtime, and attendance records.

## Features

- Employee Management
- Attendance Monitoring
- Payroll Computation
- Overtime Calculation
- Deduction Management (SSS, PhilHealth, and HDMF)
- Allowance and Incentive Management
- Cash Advance Tracking
- Payroll Reports Generation

## Technologies Used

- Java
- MySQL
- JDBC
- Eclipse IDE
